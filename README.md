This repository has the following R codes:

1. DE_analysis.R -

    To perform differential gene expression analysis using deseq2
    
    To generate a heatmap and add annotation using the ComplexHeatmap package

2. Seahorse_v2.R -
   To calculate the metabolic measurements for all the parameters.
  
3. neuron_counts.R -
To calculate fluorescence variation measurements (ΔF/F) in each frame of all the neurons, followed by calculating the frequency and amplitude of calcium events (with a threshold value of ΔF/F>2) for each larvae recorded.
